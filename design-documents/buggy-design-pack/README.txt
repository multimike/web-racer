BUGGY DESIGN PACK — ORIGINAL STYLES — v1.0

Four individual design handoffs for later 3D modeling:
  neon-wasp/
  reef-rocket/
  riot-ram/
  comet-fox/

Each folder contains:
  turnaround.png       Front, left side, rear, top and perspective views
  modeling-brief.txt   Suggested dimensions, palette, construction and rig notes
  model-spec.json      The same structured dimensions, wheel centers and parts
  generation-prompt.txt  Exact visual generation prompt and tool provenance

original-concepts.png preserves the first four-design sheet. It is the styling authority. The later wasteland versions are excluded.
Open index.html locally for an illustrated overview.

WHAT IS AND IS NOT FIXED
The colors, visible forms and distinct original styles are the design direction. The dimensions, unseen surfaces, rear assemblies and rig structure are proposed starting points.
The generated images are modeling references, not calibrated CAD orthographic drawings. Their five views may differ slightly in geometry, projection or detailing. Do not scale a whole image sheet and assume every view shares one exact scale. Use the wheelbase and wheel-center coordinates to set the first blockout, then reconcile the views.
Specific differences to resolve are recorded in each modeling brief, including Riot Ram's bumper cutouts and Comet Fox's turbine arrangement.
No mesh, UV textures, rig, collision model, CAD file, FBX or Blender file is included. Those are the next modeling stage.

SUGGESTED HANDOFF WORKFLOW
1. Read the buggy's modeling-brief.txt and load its turnaround.png into the DCC application as a reference.
2. Set meters and the +Y forward, +Z up master convention.
3. Block out wheel centers, body and cage before adding detail.
4. Review with the original-concepts.png and from the intended game camera.
5. Agree on target platform, driver scale and engine conventions before final geometry, UVs and export.

GENERATION
Turnarounds created with the built-in image_gen tool using original-concepts.png as the sole image reference. Exact prompts are included per vehicle.
Dimensions and colors were manually proposed for a consistent artist handoff; they are not measurements of an existing engineered vehicle.
